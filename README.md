# Портфолио

Статический сайт для демонстрации проектов заказчикам.

## Структура

```
portfolio/
├── index.html              # Главная страница (список проектов)
├── css/
│   └── style.css           # Стили (пока базовые, оформим позже)
├── js/
│   ├── projects-data.js    # Данные о проектах — здесь добавляются проекты
│   └── main.js             # Логика: отрисовка карточек
├── assets/
│   └── images/             # Картинки и превью проектов
└── projects/               # Отдельная страница под каждый проект
    ├── project-1.html
    └── project-2.html
```

## Как добавить новый проект

1. Добавьте объект в массив `projects` в файле `js/projects-data.js`.
2. Положите превью-картинку в `assets/images/`.
3. Скопируйте `projects/project-1.html` и заполните содержимым.

## Как запустить локально

Открыть `index.html` в браузере. Или поднять локальный сервер:

```
python3 -m http.server
```

и зайти на http://localhost:8000
